# 스튜디오 숫자 받아 대시보드에 올리기 (Claude 가 하는 절차)

대시보드의 '스튜디오 지표'(계속 시청함·평균 조회율·구독 증감·시청 시간·노출·클릭률·유입 경로·수익 조건)는
유튜브 공식 통로로는 못 가져온다(계속 시청함이 없음). 그래서 스튜디오 화면을 읽어서 채운다. 읽기만 하고 아무것도 누르지 않는다.

## 준비
1. 받이 켜기(백그라운드): `python studio/collect_server.py` (127.0.0.1:8765, 끝나면 끈다)
2. 브라우저에 세 계정이 로그인돼 있어야 한다. 안 돼 있으면 사용자에게 로그인을 부탁한다(비밀번호는 사용자가 직접).

계정이 여러 개 로그인돼 있으면 주소에 `authuser=N` 을 붙여야 그 계정으로 열린다(안 붙이면 '권한이 없습니다').
2026-11-13 앱 안 브라우저 기준: `authuser=0` dhsmfehwkf / `authuser=1` panreadkr / `authuser=2` moneycasekr.
순서는 로그인한 차례라 바뀔 수 있다 → '권한이 없습니다'가 뜨면 0·1·2 를 바꿔 본다.
표 주소는 `explore?authuser=N&entity_type=...` 처럼 `explore?` 바로 뒤에, 수익 조건 주소는 끝에 `?authuser=N`.

## 채널마다 표 4개 (ID 자리에 채널 ID)
공통 앞부분: `https://studio.youtube.com/channel/ID/analytics/tab-overview/period-default/explore?entity_type=CHANNEL&entity_id=ID&explore_type=TABLE_AND_CHART&metric=EXTERNAL_VIEWS&granularity=DAY`

1. **videos** (영상별, 전체 기간) — 뒤에 붙임:
   `&time_period=lifetime&t_metrics=EXTERNAL_VIEWS&t_metrics=ENGAGED_VIEWS&t_metrics=EXTERNAL_WATCH_TIME&t_metrics=AVERAGE_WATCH_TIME&t_metrics=AVERAGE_WATCH_PERCENTAGE&t_metrics=SHORTS_FEED_IMPRESSIONS_VTR&t_metrics=SUBSCRIBERS_NET_CHANGE&t_metrics=RATINGS_LIKES&t_metrics=SHARINGS&t_metrics=COMMENTS&t_metrics=VIDEO_THUMBNAIL_IMPRESSIONS&t_metrics=VIDEO_THUMBNAIL_IMPRESSIONS_VTR&dimension=VIDEO&o_column=EXTERNAL_VIEWS&o_direction=ANALYTICS_ORDER_DIRECTION_DESC`
2. **daily** (날짜별, 최근 28일):
   `&time_period=4_weeks&t_metrics=EXTERNAL_VIEWS&t_metrics=ENGAGED_VIEWS&t_metrics=EXTERNAL_WATCH_TIME&t_metrics=SUBSCRIBERS_GAINED&t_metrics=SUBSCRIBERS_LOST&t_metrics=AVERAGE_WATCH_PERCENTAGE&t_metrics=SHORTS_FEED_IMPRESSIONS_VTR&t_metrics=VIDEO_THUMBNAIL_IMPRESSIONS&t_metrics=VIDEO_THUMBNAIL_IMPRESSIONS_VTR&dimension=DAY&o_column=DAY&o_direction=ANALYTICS_ORDER_DIRECTION_DESC`
3. **traffic** (유입 경로, 최근 28일):
   `&time_period=4_weeks&t_metrics=EXTERNAL_VIEWS&t_metrics=ENGAGED_VIEWS&t_metrics=EXTERNAL_WATCH_TIME&dimension=TRAFFIC_SOURCE_TYPE&o_column=EXTERNAL_VIEWS&o_direction=ANALYTICS_ORDER_DIRECTION_DESC`
4. **monet** (수익 조건): `https://studio.youtube.com/channel/ID/monetization/overview`

각 화면을 열고 8~9초 기다린 뒤:
- 표 1~3: `studio/send.js` 를 맨 끝 `"NAME"` 만 `"<short>_videos"` 식으로 바꿔 화면에서 실행 → `{rows, range, more, err, sent}` 가 돌아온다.
  · `rows` 가 0 이거나 `err` 가 true 면 화면을 조금 내렸다가 다시 실행(숨은 창에서는 표가 늦게 그려진다).
  · `more` 가 true 면 영상이 50개를 넘은 것 → 다음 쪽도 받아야 한다(send.js 는 첫 쪽만 보냄. 그때 고친다).
  · 보낸 뒤 **3초 기다렸다가** 다음 화면으로 간다. 바로 넘어가면 보내던 조각이 끊겨 파일이 안 생긴다(2026-11-13 돈이 된 사건 영상 표에서 겪음).
  · 다 받은 뒤 `studio/raw/*_videos.json` 의 줄 수가 0 이 아닌지 확인한다.
- 표 4: `studio/send_monet.js` 를 같은 식으로 `"<short>_monet"`.
- 같은 계정의 두 번째 채널이 '권한 없음'으로 뜨면 youtube.com/channel_switcher 에서 그 채널을 고른 뒤 다시 연다(끝나면 원래 채널로).

## 합치고 올리기
```
python studio/merge.py          # studio/raw → data/studio.json (받지 못한 채널은 이전 값 유지)
git pull --rebase               # GitHub 이 1시간마다 data 를 커밋하므로 먼저 받는다
git add data/studio.json && git commit -m "studio YYYY-MM-DD" && git push
```
받이를 끈다. 스튜디오 표는 이틀쯤 늦게 집계되므로 하루 한 번이면 충분하다.
